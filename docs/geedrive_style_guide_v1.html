Usage Rules
Do & Don't
Do
Use amber-600 (#A56210) for text on light backgrounds — it passes AAA contrast and aligns with the brand.
Don't
Use amber-400 (#D4891A) as body text on white — it only passes AA at large sizes, not for small body copy.
Do
Pair every status badge colour with an icon and a text label — colour alone is never the only signal.
Don't
Use a green/red dot alone to indicate status — colour-blind users and screen readers cannot interpret it.
Do
Use Barlow Condensed 700+ for all headings, metric values, and card titles — it echoes the logo and creates strong hierarchy.
Don't
Use Barlow Condensed for body copy or hint text — it loses legibility below 14px and reads as shouting in paragraphs.
Do
Keep the amber focus ring (0 0 0 3px rgba(212,137,26,0.35)) on every interactive element — it is the primary keyboard navigation signal.
Don't
Remove or suppress outline/focus-visible styles — this breaks keyboard navigation for all users.
